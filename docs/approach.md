# Our approach

A good interface often depends on small decisions: the weight of a border, the response to a pointer, the pace of a transition.

## Start small

Next UI collects focused interaction patterns rather than a whole design system. Add one where it earns its place. An interface does not need every effect at once.

## Keep the source close

Copy the implementation into your project. Read it, simplify it, and adapt it. There is no remote configuration and no hidden runtime service.

## Make the interaction fit

Motion should help the interface feel responsive without competing with the task. Prefer a quiet static treatment when animation adds little. Test touch, keyboard, and reduced-motion behavior alongside the visual design.

## Build in the open

The repository includes the showcase, component examples, documentation, and verification scripts. See [contributing](contributing.md) to improve an example or report a problem.
