# Privacy

The Next UI website is a component showcase and documentation site. It has no account system, contact form, analytics script, or advertising integration in this repository.

## Search and clipboard

Search and component filters run in your browser. Search text is not sent to a search service. Copy controls write only the selected source or documentation to your clipboard after you activate them.

## External destinations

GitHub and optional AI chat links open external services with their own privacy policies. AI links include a prompt containing public documentation, never local application files. Review the prompt before submitting it.

## Hosting

A hosting provider may process ordinary request information such as IP addresses and user agents. The exact provider and retention depend on how this repository is deployed.
