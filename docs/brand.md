# Brand & assets

Next UI uses a geometric N monogram with a diagonal cut, black surfaces, white typography, and ordered dither textures. The wordmark is `smeltery / next-ui`.

[Explore the brand page](/brand) for logo specimens, the social preview, copyable colors, typography, and individual downloads.

## Colors and typography

| Role    | Value     |
| ------- | --------- |
| Paper   | `#080808` |
| Ink     | `#f5f5f5` |
| Accent  | `#e0e0e0` |
| Surface | `#181818` |

DM Sans is used for interface text and headings, with Georgia for editorial emphasis. Technology logos identify the tools used by the project; they do not imply endorsement.

Supporting artwork uses a one-bit, ordered-dither N specimen. Keep textures decorative and away from body text. The artwork is a static SVG: no canvas runtime or animation is required.

Keep the logo’s diagonal gap and proportions intact. Leave at least one stem-width of clear space around the tile, and use it at 16 pixels or larger. Use the supplied SVG for scaling; keep dither textures outside the logo itself.
