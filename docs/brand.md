# Brand & assets

Next UI uses a compact N monogram, black surfaces, white typography, and ordered dither textures. The wordmark is `smeltery / next-ui`.

The social image is 1200 × 630 pixels. Keep its proportions when sharing it.

## Colors and typography

| Role    | Value     |
| ------- | --------- |
| Paper   | `#080808` |
| Ink     | `#f5f5f5` |
| Accent  | `#e0e0e0` |
| Surface | `#181818` |

DM Sans is used for interface text and headings, with Georgia for editorial emphasis. Technology logos identify the tools used by the project; they do not imply endorsement.

The hero uses a one-bit, ordered-dither N specimen. Keep textures decorative and away from body text. The artwork is a static SVG: no canvas runtime or animation is required.
