# Brand & assets

Next UI uses a compact N monogram, warm paper surfaces, and muted sage accents. The wordmark is `smeltery / next-ui`.

## Colors and typography

| Role   | Value     |
| ------ | --------- |
| Paper  | `#f7f7f2` |
| Ink    | `#292b25` |
| Accent | `#526447` |
| Sage   | `#eceee5` |

DM Sans is used for interface text and headings, with Georgia for editorial emphasis. Technology logos identify the tools used by the project; they do not imply endorsement.
